# Factory Lane Windows & Doors

Website for factorylane.ca.

## Deployment

- Hosting: Cloudflare Pages (`factorylane-ca`).
- Production branch: `main`.
- Framework preset: None.
- Build command: empty (plain static HTML).
- Build output directory: `public`.
- Preview: https://factorylane-ca.pages.dev

Commits to `main` automatically trigger a production deployment. Only files in `public` are published as website assets.
